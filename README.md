# Portfolio Data & Storage Vault (CodexSidou)

This repository serves as the central cloud data and storage repository for the [CodexSidou Portfolio](https://github.com/CodexSidou/Portfolio).

## Contents
- \site-data.json\: The authoritative JSON data store containing all projects, hero content, skills, work history, services, and configuration.

## Direct CDN Access
- **Raw URL**: \https://raw.githubusercontent.com/CodexSidou/portfolio-data/main/site-data.json\
- **jsDelivr CDN**: \https://cdn.jsdelivr.net/gh/CodexSidou/portfolio-data@main/site-data.json\

## Updates & Persistence
Any project or content saved in the admin panel can be synced here so that updates persist permanently across devices and deployments without resetting.
